# Sakshi Saini — Cinematic Fashion Portfolio

A luxury-editorial portfolio for **Sakshi Saini, Apparel Designer**, built from her
*KAZO SS27 / Modern Romance* assignment PDF. Every photograph, garment illustration and
technical drawing is an **original image extracted from the PDF** — nothing is generated.

**Stack:** React 19 · TypeScript · Vite · Tailwind CSS v4 · GSAP + ScrollTrigger · Lucide

## Run it

```bash
npm install
npm run dev        # http://localhost:5173
npm run build      # typecheck + production build into dist/
npm run preview
```

## Adding real personal details

Personal facts are **not invented**. Anything unverified renders as a dashed, italic
placeholder. To fill them in, edit `src/content/site.ts`:

- `about.facts` — city, education (empty `value` = placeholder shown)
- `contact.email / linkedin / instagram / portfolioPdf` — empty = placeholder shown

The contact form is a **frontend demonstration**: it validates and tells the visitor no
message was sent. To go live, post the form to a backend in `components/sections/Contact.tsx`
(`onSubmit`) and update `contact.formNotice`.

## Re-generating images from the PDF

Requires `poppler` (`pdfimages`) and Pillow. Put the PDF at `Prompt/SAKSHI SAINI ASSIGNMENT.pdf`, then:

```bash
npm run assets
```

It extracts the embedded images (first run takes a couple of minutes, then cached in
`.cache/`), composites soft-masks into real transparency, trims cut-out margins, removes
an embedding artefact, and writes responsive WebP + the manifest. The source-page mapping is the
`SOURCES` table at the top of the script. The PDF itself is git-ignored (94 MB).

## Animation & accessibility notes

- Scroll animations are declared with data attributes (`data-reveal`, `data-stagger`,
  `data-split`, `data-mask`, `data-parallax`, `data-line`) and applied by `useReveals`.
  Content is visible by default; GSAP only hides things when motion is allowed.
- **Never** put a CSS `transition` on opacity/transform of an element GSAP animates — they fight.
- `prefers-reduced-motion`: short fade preloader, no pinning, no reveals, native scroll lookbook.
- Desktop lookbook pins and scrolls horizontally; elsewhere it is a swipeable scroll-snap strip.
- Dialogs use native `<dialog>` (focus trap, Esc, focus return). Everything is keyboard reachable.
- Images always carry width/height (no layout shift), lazy-load below the fold, and ship alt text.
- Heads-up: an `<img>` with `srcset` + `sizes` takes its intrinsic width from `sizes` —
  size images explicitly (`h-full w-full object-contain`) rather than `w-auto`.

## Content honesty

The About biography is *suggested portfolio copy* and is labelled as such. The KAZO work is
presented as a **portfolio project**, not employment or client work. The Celeste Schiffli Midi
Skirt shares the set's documented specs; fields the PDF doesn't state are marked, not invented.
